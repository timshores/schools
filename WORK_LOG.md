# Work Log - School Data Analysis Project

Work log entries have been split into individual files in the `work_log/` folder for easier ingestion.

- **Index:** `work_log/_index.txt` — lists all session files with descriptions
- **New entries:** Create new files in `work_log/` following the naming pattern: `YYYY-MM-DD_sessionN_short_description.txt`
- **Reading recent context:** Read `work_log/_index.txt` first, then read whichever recent session files are relevant.
